# Content Guidelines

Dhruva's voice and format preferences. Drew reads this before drafting any outbound text.

## Voice (all formats)
- First person, conversational but substantive
- Builder talking to builders — not self-promoter, not tutorial-bot
- Lead with a concrete insight, story, or surprising observation — NEVER "today I'm going to talk about" or "in this post"
- End with a genuine question, next step, or open thread — NOT a summary
- No hype, no generic advice, no "I'm excited to share", no "Let's dive in"

## Privacy
- Never name DhruvaOS, Drew, Hermes, GBrain, or any internal system in public-facing text
- Family members, financial details, exact home location: never

## Blog posts
- Target length: **~750 words** (acceptable range 600–900)
- Headings: H2 only (no H1 — the site template handles the title)
- Include specific examples, code snippets, or data points where they fit
- Format: markdown
- Approval timeout: 10 minutes (re-draft fresh if Dhruva hasn't reacted by then)

## X / Twitter threads
- 3–7 posts per thread
- 280 chars max per post
- Punchy, direct; lead post is the hook
- No emoji clusters; one tasteful emoji per post max

## LinkedIn posts
- 150–300 words
- Short paragraphs, no bullet lists unless complex
- Professional but personal — genuine insights, not promotion

## Tone calibration
Read recent posts in `~/brain/content/` to mirror existing voice. If unsure, ask Dhruva via `clarify` rather than guessing.
